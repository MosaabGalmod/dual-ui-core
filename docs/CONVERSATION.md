# توثيق تأسيس مهارة Dual-UI Core

**تاريخ التأسيس:** 30 سبتمبر 2026  
**المطور:** المهندس محمد مصعب الجلمود (Muhammad Mosaab Algalmod)  
**الهدف:** هندسة واجهات ويب احترافية ثنائية اللغة (عربي RTL وإنجليزي LTR) مع عزل تام يمنع تسرب أي لغة للأخرى، ودعم كامل للنمطين الداكن والفاتح مع أزرار التحكم الفورية وحفظ التفضيلات.

---

## 1. متطلبات المهارة الأساسية
1. **العزل اللغوي الصارم (Zero Text Leakage)**:
   - منع تضمين النصوص الثابتة (Hardcoded Strings) داخل القوالب نهائياً.
   - قواميس ترجمة مستقلة للغتين.
   - عدم ظهور أي مفردة إنجليزية في الواجهة العربية، ولا أي مفردة عربية في الواجهة الإنجليزية.
   - حماية وعزل الاختصارات والمصطلحات التقنية في الواجهة العربية باستخدام وسوم `<bdi>`.
   - استخدام علامات الترقيم العربية (`،` `؛` `؟` `« »`) حصرياً في النصوص العربية.

2. **التنقل الهيكلي المنطقي (CSS Logical Properties)**:
   - منع استخدام `left` و `right` في هوامش وحشوات الهيكل، واستبدالها بـ `margin-inline-start/end` و `padding-inline-start/end`.

3. **النمطان الداكن والفاتح (Dual-Theme Tokens)**:
   - بناء لوحة ألوان دلالية عبر متغيرات CSS مع خطوات تباين مريحة للعين ومطابقة لمعايير WCAG AA.
   - زر تحكم تفاعلي للشمس والقمر.

4. **منع الوميض (Anti-FOUC)**:
   - تنفيذ كود مصغر في ترويسة الصفحة لقراءة تفضيلات `localStorage` وتطبيق اتجاه ونمط الصفحة قبل رسم الـ DOM.
